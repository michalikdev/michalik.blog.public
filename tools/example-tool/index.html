form-worker

One Cloudflare Worker that validates a form, drops the obvious spam and forwards the rest. No dependencies.

serverlesscloudflaretooling

github.com/michalikdev →

Runtime
Cloudflare Workers
Dependencies
none

The endpoint a static site does not have. Validation, a honeypot field, a per-address rate limit, and a secret target address that never reaches the browser.

It deliberately does not store anything itself: the destination is configuration, so the same Worker can point at a spreadsheet today and a database later without the form ever knowing.
